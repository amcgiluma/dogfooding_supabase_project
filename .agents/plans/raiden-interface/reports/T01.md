# T01 report: Raiden interface mockups

## Delivered

- `docs/raiden-interface/index.html` — Spanish comparison page with three inline layout silhouettes and direct links.
- `docs/raiden-interface/command.html` — dense navigation, conversation, and operations rail.
- `docs/raiden-interface/signal.html` — open conversation with a mission strip, collapsible details, and inline mission selector.
- `docs/raiden-interface/vector.html` — large asymmetric mission heading with a separate stage and event column.

Each product preview uses the supplied local Rajdhani and IBM Plex assets, inline CSS and JavaScript, and a Spanish state selector. The six selector states are shareable through `?state=`. Local controls cover example prompts, chat entry, mission creation, permission choices, review approval, feedback, and mission detail toggling. Mission creation uses App, Research, Monitoring, and Custom, with Research selected by default, three stages, and a target date set to seven days from the current local date whenever the dialog opens.
