During onboarding render only Onboarding plus existing storage state and reset access without a competing header/footer; T01 owns internal wordmark. Preserve reset `<dialog>`, storage warning, Retry saving, resetPending/error behavior and explicit reset confirmation; retain concise visible Local demo marker and reset access in sidebar/menu, not a large global footer. Fix rejected retry errors visibly if current shell lacks display outside recovery.
3. Implement small App-owned Sidebar component if helpful. Desktop sidebar contains `morrow+`, empty corner-marker mascot mount with selected companion name and brief A3 personality, General chat, New mission, compact mission rows with status, Companions management link and profile/reset controls at bottom. Use companion selector when more than one companion; changing selection navigates that companion's general chat. Selection state uses existing `view`, `getCompanionMissions` etc, never independent duplicated domain state. Clicking mission navigates existing workspace view with its scoped ID. Sidebar works without any companion. Create/rename companions remains accessible from Home management. Empty mascot mount must replace ALL skull/wolf artwork in app/sidebar/home, no placeholder character/initial art.

Close on navigation/create selection. Restore focus to menu opener after close, trapping focus through native modal semantics. Keep dialog states coherent on breakpoint changes (close mobile modal when returning desktop). Avoid duplicating focus IDs across desktop/dialog navigation. A tiny shared typed viewport hook is acceptable with listener cleanup.

Keep no-profile initialization/reset at home so Onboarding appears. Do not persist new routing fields or modify schema/action queue/storage semantics. `navigate` validation stays intact. Maximum 760px centered transcript and composer, assistant copy on black with white speaker name plus blue slash, user responses aligned right on #18181b, whitespace preservation and arbitrary word wrapping.    Preserve edit goal for noncompleted missions and correction text validation/error/pending/focus behavior.
